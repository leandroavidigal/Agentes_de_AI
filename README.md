# 🤖 Hub de Agentes de IA — Projetos & Experimentos

Bem-vindo(a) ao meu **repositório central** de **Agentes de Inteligência Artificial**!
Aqui você encontra projetos práticos que combinam **IA + Engenharia de Dados + Apps interativos** (principalmente em **Python/Streamlit**), com foco em **resolução de problemas reais**, visualizações e relatórios.

> 🔎 Curioso/curiosa? Explore abaixo a lista de projetos, rode localmente e sinta-se à vontade para abrir issues e sugerir melhorias!

---

## 🚀 Destaques

* **Agentes com propósito**: cada projeto foca em um domínio (fraude, EDA, automação, etc.).
* **Experiência completa**: UI, gráficos, métricas, relatórios (PDF/HTML) e *insights* com LLM.
* **Stack moderna**: Streamlit, Pandas, LangChain + OpenAI, entre outras libs.
* **Reprodutível**: `requirements.txt`, guias de execução e exemplos.
* **Foco em boas práticas**: separação de segredos, `.gitignore`, organização em pastas.

## 🤝 Contribuindo

Contribuições são muito bem-vindas!

1. Faça um fork e crie uma branch: `feat/nome-da-ideia`
2. Descreva claramente o objetivo e o impacto
3. Respeite padrões: isolamento de segredos, `requirements.txt`, `README` por projeto
4. Abra um Pull Request — discutimos juntos!
